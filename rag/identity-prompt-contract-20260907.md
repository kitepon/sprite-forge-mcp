# プレビューNGをLoRA作り直しで直す、という前提の再点検

取得日2026-09-07。一次資料と当日の隔離実測。髪型は検証例であり、研究対象は特定NG事例の再発抑制。

## 結論

教材の採否・説明を直して焼き直す、本人OKの生成を足して焼き直す、の二手は当日実測で不成立。世の中のLoRA運用と公式ドキュメントは、その失敗と矛盾しない。学習キャプションに出した特徴は生成文でも要求され、キャプションに出さなかった特徴だけがトリガーへ吸着する。自分の生成を教材に戻すと、珍しい属性は太らず消えやすい。NG指摘の反映先として、学習を触らず生成の内容指定へ載せる経路が、文献と製品の三段階の両方と合う。

## 当日実測（前提）

隔離キャッシュでキャラクターLoRAをAnima Baseから作り直した。生成文に髪の語句は足していない。本人採否ではない。

- 元教材の見直しのみ: seed 601–610 で元LoRAも作り直しもツインテール 3/10
- 見直し済み元5枚に本人OK生成6枚を足す: seed 611–620 で元 5/10、作り直し 7/10、OK追加 4/10

OK追加は held-out で増えていない。14秒で完了した前回学習は教材0枚の失敗で、本数には含めない。

同じ作り直しLoRA・seed 601–610で、生成文へ `twin tails` だけ足した対照では、単体全身のツインテールが 3/10 から 8/10 になった。設定画シート2枚は髪はツインテールだが複数カットのまま。学習していない。閲覧は compare-prompt.html。

## 学習と生成の契約

[kohya sd-scripts の学習README](https://github.com/bmaltais/kohya_ss/blob/master/docs/train_README.md)は方式を分けて書く。識別子だけでキャプションを付けない学習は、髪型・衣装・背景まで識別子へ結び付く。画像ごとに詳しく書く学習は、キャラクターと他要素を分け、生成時にその要素を指定しやすくする。

[WAI-Anima向けのキャプション実測](https://lilting.ch/articles/wai-anima-lora-caption-rework)（2026-04、同一著者の英語版あり）は同じ分岐をAnimaで見ている。髪型タグを学習キャプションに入れずトリガー一語へ吸わせると、生成時に髪型を書かなくても出る。入れると独立タグになり、生成時に `twin tails` 等を足さないと出ない／バラける。著者は変えたい髪のために後者を選んでいる。トリガーだけで固定したい目的とは逆。

Anima公式の推奨キャプションは Danbooru タグ列のあと任意で自然言語、という組み合わせである。当日の作り直し・OK追加は英語の説明文へ髪を書き、評価生成文には髪を書かなかった。これは「トリガーだけで出せ」という試験と、「髪は別概念として学べ」という学習が同時に成立しない契約である。

製品の `dataset_config` は `shuffle_caption` と `keep_tokens` を付けない。`box/smoke-dataset.toml` だけがそれを持つ。当日失敗の主因と断定はしない。

## 自分の生成を足すこと

[Nature 2024 の model collapse](https://pmc.ncbi.nlm.nih.gov/articles/PMC11269175/)と [Chain of Diffusion の LoRA再学習](https://arxiv.org/abs/2407.17493)は、モデル出力を再度学習すると分布の裾が消えると報告する。当日のOK6枚は同じ生成系の当たりであり、文献の多世代崩壊そのものではない。ただし「珍しい当たりを教材に足せば頻度が上がる」を支持する一次資料ではない。

## NG反映として文献にある他の手

| 経路 | 何をするか | 今回との関係 |
| --- | --- | --- |
| 生成の内容指定 | 学習で独立させた特徴を、次の生成文へ書く | 学習ゼロ。画風語句の埋め込み禁止とは別。被写体の内容指定 |
| 設定画・台帳の修正を次の生成で使う | 製品の三段階が既に持つ | プレビューNGをLoRA再学習へ送らない |
| Concept Sliders | 同じ構図の差から属性方向のLoRAを重ねる | [著者解説](https://sliders.baulab.info/)。対応画像が要る。旧局所選好の近く |
| Diffusion-DPO / KTO | 画像全体の好き嫌い | 部位を指定しない。当日以前の試作で改善未達 |
| ESD / LECO | 文章で概念を消す | 当日以前の試作で、この検証例では不成立 |
| マスク・点・言葉で描き直す | 製品方針の修正経路 | 手描き修復は作らない |

IP-Adapter や別基盤への切替は、現行採用の Anima + キャラクターLoRAを黙って置き換えることになり、今回の対象外。

## 生成文対照の実測

学習を増やさない対照を実施した。作り直しLoRAと seed 601–610 は前回と同一。変えたのは生成文のトリガー直後へ `twin tails` を足したことだけ。画風語句は入れていない。単体全身のツインテールは髪なし 3/10、あり 8/10。この検証例では、壊れているのは重みではなく学習キャプションと生成文の契約だった。トリガーへ吸着させたいなら、その特徴をキャプションから外し、画像がその特徴を実際に示す教材だけで焼く対照は未実施。Animaでは吸着と向き制御がトレードオフという一次実測がある。
