# 画像と指摘による汎用NG反映

取得日2026-09-07。一次資料とローカルコードを照合。Animaでの汎用的な抑制効果は未実証。

研究対象は特定のNG事例の再発抑制。髪型は検証例の一つで、衣装や構図等でも同一処理を使う。過去の資料にある「必要なのは髪型の修正」という目標の限定は、今回のオーナー裁定により撤回された。

| 方法 | 入力と適用範囲 | 判断 |
| --- | --- | --- |
| [ESD](https://erasing.baulab.info/) | 消す概念の文章と凍結モデルの予測。物体・画風など複数分野の研究 | 画像と指摘から概念を取り出す共通処理を接続する基準方式。画像自体を直接学習する方法ではない。 |
| [Forget-Me-Not](https://github.com/SHI-Labs/Forget-Me-Not) | 概念の文章、必要なら画像から学習した埋込み。注意を抑制 | 言語化で失われる具体的な見た目を扱う比較候補。SDの埋込み更新をAnimaへ移植する追加検証が必要。 |
| [Diffusion-NPO](https://github.com/G-U-N/Diffusion-NPO) | 既存選好手法を逆方向に学習して生成時の負条件に使う。公式DPO例はペア入力 | 名前だけでNG画像のみの忘却手法と解釈しない。今回のOKペア不要条件をそのまま満たす根拠にはしない。 |
| [PUREの投稿論文](https://openreview.net/pdf?id=BRJserk9XM) | 負例のみの目的と保持データによる修復を交互に実行すると記述 | OKペア不要と保持データ不要は異なる。投稿時点の主張であり、Anima実証と扱わない。 |

ローカルのprobe_local_vlm.pyは、観察と比較の指示が髪型に固定されていた。box/esd_train.pyの通常ESD計算には髪の分岐はないが、前回の保持実験は定位句hairを固定していた。新しい共通解釈はevidence/ng-generalization-20260907に隔離する。モデルの生応答、入力画像、本人原文と研究用原文を全件表示する。

推論上の注意：ESDの全画面誤差へ同じ入力に対する全画面の参照予測保持誤差を足すだけなら、二つの目標の加重平均へ近づけるのと等価になる。これを特定のNGだけを分離する新しい保持技術とは呼ばない。抑制対象の取り違えと、学習後の対象外変化は別に測る。
