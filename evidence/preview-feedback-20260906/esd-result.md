# OK教材を使わないESD実証

2026-09-06。オーナーの「では進めろ。やってみせろ。」に基づく実行。工程記録はLattice preview-feedback-20260906 / 01-feasibility。旧OK対学習は行わない。

## 方法

ESDの属性除去をAnimaへ移植。除去概念は `short bob haircut`、対象条件は既存キャラクターprompt。凍結した元LoRA込みの予測について、対象条件のFlow速度から、除去概念と空条件の速度差を引いた教師信号を使う。DiT LoRAだけを更新し、元のQwen3重みは保持。OK画像、元NG画像、合成画像、マスクは学習入力に含めない。事前にseed106/109で通常指定とボブ指定の4画像を生成し、対象となる顎付近の下ろし髪が文章に対応することを目視した。

20更新、学習率1e-5、negative guidance 1、学習seed37。潜在は16×76×52（416×608相当）。元モデルから8段階のEuler・CFG4でランダム段階まで生成して学習する。最終比較はAnima Base 832×1216、28steps・CFG4・LoRA強度0.8。学習前後でprompt/negative/seedを同一にし、NG髪型の文章を追加しない。

## 結果

| 評価項目 | 学習前 | ESD後 |
| --- | --- | --- |
| NGのボブ髪・全12枚 | 7 | 4 |
| NGのボブ髪・未使用seed301〜310 | 5/10 | 3/10 |
| NGのボブ髪・既知seed106/109 | 2/2 | 1/2 |
| 単体の全身像 | 11/12 | 9/12 |

302と308がツインテールに、106が長い下ろし髪になった。109/305/307/310はボブのまま。301/308には新しい顔カットが付いた。紫系の瞳と衣装の基本構成は12枚とも残ったが、腕の姿勢、胸元・スカートの細部は変わる。NG除去をツインテールへの正解化と混同せず、全24枚を目視した。本人の画像採否とは別。

学習実行34.53秒、最大割当9,417,331,200 bytes、元LoRAファイル不変、凍結基準不変、保存再読込み誤差0。LoRA変化二乗和0.0506976339。出力重みはfoxの `ng-esd-20260906.safetensors`。採用中LoRA・台帳は上書きしていない。本番コンテナ再配備なし。

初回はT5 token IDsがCPUに残り、最初の順伝播で停止。既存Anima入口と同じく条件テンソルをGPUへ転送して修正。更新前の失敗ログはtrain-failed-1.logへ保持し、明示再実行で成功。無言の再試行はしていない。
