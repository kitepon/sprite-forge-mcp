# シート構成の保存・生成経路の確認

2026-09-05。開始HEAD d7f8ffc。対象は構成の共通サービスと既存画面の描き直し一覧。水着・下着は試験データだけで、製品へ固定条件を追加していない。

## 実装と判定

構成の追加・削除・並べ替え・表示名と内容の変更をRESTとMCPの同じサービスで保存する。次回の構成と完成したシートの構成を分離し、変更した内容へ旧修正が混入しない。Seedの差分は項目に保持して、並べ替えだけで変化させない。任意件数を生成し、その構成からPNGとHTMLを合成する。旧記録は構成が存在しない場合だけ従来23項目として読む。

反証で見つかった、旧シートを描き直す間に新シートが完成した場合の旧修正記録の欠落と、同じ構成の別シートへ旧注文を適用できる問題を修正した。前者は描き直しジョブに対象シートを残し、後者は注文に対象シートの既存job_idを持たせて確認・生成時に照合する。対応するfocused testを追加した。

29項目の合成試験で末尾が12px不足する原因を確認し、キャンバスの高さを構成から計算する式を直した。日本語見出しは既存OSの対応フォントで表示を実測した。DockerとCIへNoto CJKの導入を追加したが、そのLinux環境での実行は本単位では未確認。
