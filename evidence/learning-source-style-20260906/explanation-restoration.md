# 学習ページの解析説明を復元

2026-09-06。旧解析案に新しい採用方針がない場合、開始操作とともに解析説明まで非表示にした変更を修正した。

- `web/intent.js` に保存済み解析の表示を設けた。採用理由、参照画像、画像ごとの日本語説明、原文、英語の生成文・教材説明、確認事項を保存データから表示する。過去の案を採用済みと見せたり、データを書き換えたりしない。
- `web/learning.js` で進捗表示とは別に解析説明を残す。旧形式・読取り中・学習中・完了後にも閲覧できる。最新の確認中の案は既存の確認画面で表示し、過去の案は履歴から開ける。
- 学習ページへ別画風の選択・希望を放棄するチェックは戻さない。既存の学習開始条件とバックエンドは変更していない。

関連する20試験を確認後、全Python274件・WebUI43件に成功。本番のAPIをGETだけで参照するローカル確認画面で、実際のベルの旧解析文、4項目の採用理由、6枚分の説明を表示した。幅390pxでも横方向のはみ出しなし。英語の詳細を開けること、再解析や学習を起動せずに閲覧できることを確認した。

画像・解析記録・学習データの削除や変更は行っていない。今回の修正は説明表示だけで、実機学習や生成品質の再評価は対象に加えていない。
