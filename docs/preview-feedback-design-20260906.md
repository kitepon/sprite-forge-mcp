# プレビューのOK／NGを再学習へ反映する設計

2026-09-06。オーナー依頼に基づく実装計画の設計資料。今回は計画作成のみ。製品コード、GPU学習、本番データ、配備を変更しない。

工程・依存・進捗・実装完了証拠はLatticeの `preview-feedback-20260906` を正本とする。本書は要求、設計判断、受入条件を持ち、実行チェックリストを持たない。既存の `user-intent-agent-20260905` の完了したコメント機能を利用する。

## オーナーの要求

- 一回に10枚ほどのプレビューを生成し、各画像にOK／NGを付けられる。
- 生成画像へのOK／NGの両方を再学習へ反映する。
- 再学習後の画像を確認し、設定画へ進むか、もう一度直すか選べる。

## 確認済みの現状

`web/flows.js` のプレビューは2枚固定。`backend/services.py` は同じ生成条件・LoRAでseedを変えて生成する。`web/jobs.js` の「候補」は表示名であり、採用を保存する操作ではない。

「顔・体形・衣装を調整する（任意）」には既存の日本語注文機能がある。参照はキャラクターの登録サンプルだけで、生成した候補は注文の画像入力に含まれない。採用した共通条件は設定画に引き継がれるが、LoRAの再学習にはならない。

現行の学習は `backend/services.py` → `backend/box.py` → `box/train.py` → sd-scripts。画像と説明、教材の採否・頻度は扱うが、生成画像の好ましい／好ましくないという組を渡す契約はない。

## 利用者の操作

プレビューの主画面は「注文」「生成画像と判定」「判定を使う操作」を常時表示する。既存の日本語注文機能を再利用し、通常の修正操作を詳細設定に隠さない。

生成は既定10枚。一枚完成するごとに表示し、生成済みの画像から判定できる。カードは元のサンプルと区別して「生成画像1」等と表示する。各カードにOK／NG、判定解除、任意の理由欄、拡大を置く。初期値は未判定。AIはユーザーの判定を代行しない。

OK／NGと理由は自動保存し、保存中・保存済み・失敗を画像ごとに表示する。画面を再表示しても同じ画像へ復元する。NG理由の入力やAIによる解釈を、再学習の必須手順にしない。

「この判定で再学習する」は、現在保存済みの判定から学習データを固定し、教材転送・学習・10枚の再プレビューまで一回の操作で実行する。生成や判定だけでは学習を始めない。途中で判定を直しても実行中の教材は変えず、次の学習に使う。二重クリック・通信切断後の再接続で同じ要求から重複学習を作らない。

再学習後は旧版・新版の画像を並べ、今回の学習に使った判定と理由を読めるようにする。「この学習結果を使って設定画へ」で、表示している新版LoRAを明示的に採用する。再学習完了だけで設定画を生成したり、画像品質を合格表示したりしない。旧版を使い続ける選択も残す。

## 学習方式の判断

第一候補は、同一の注文・生成設定で得たOKとNGを対にし、両者の相対的な評価をLoRA更新に使う選好学習。Diffusion-DPOを出発点にするが、採用確定ではない。Animaの学習目的に適合する式と実装を最初に検証する。

公開Diffusersの例はSD／SDXL向け。Animaの上流学習コードはrectified flowの目標を扱うため、SDXL用の損失式・重み付けをそのまま移植しない。foxに導入済みのsd-scriptsのremote・commit・実コードを読み、上流との差と拡張点を固定する。計画作成時点では実機版の対応を未確認とする。

最小試作では凍結した学習前モデルを基準に、学習するLoRAだけ更新する。基準は「今回の追加学習前のキャラクターLoRAを含むモデル」であり、素のAnimaへ誤って戻さない。元の参考画像による本人の特徴の維持も比較対象とし、保持用の通常学習を併用する必要性と重みは実測で決める。追加LoRAを無制限に積層せず、推論時に扱うキャラクターLoRAは一つの版とする。

OK画像だけの通常追加学習を比較対照に置く。これは選好学習の効果を確認する実験条件であり、製品の黙った代替経路にしない。NGラベルを変更・除去した時に損失と更新結果が変わることも試験する。負の重みで通常学習を逆回転させるだけの実装は採用しない。

10枚は操作上の一回分であり、改善を保証する教材数ではない。過去の判定を保持し、同じ生成元・条件のまとまりで対を作る。異なる注文や学習版を無条件に混ぜない。全組合せを独立標本と数えず、元画像・ラウンドを単位に評価を分ける。対の組み方と反復数は記録する。

両ラベルがない場合は対比較学習を開始できないことをボタンのそばに表示する。すべてOKならそのまま設定画へ進める。すべてNGなら追加生成・既存注文の修正・参考画像の見直しを選べる。元サンプルを勝手にOK扱いしたり、OKが出るまで無限生成したりしない。未判定は学習対象外とし、既存のOKとNGがあれば全画像の判定を必須にしない。

理由欄は任意の説明と比較時の確認に使う。理由だけを生成文へ足して再学習したと扱わない。理由に応じた部位マスク学習や自動評価モデルは、この要求の初回実装には含めない。

## 保存と責務

| 場所 | 変更の責務 |
| --- | --- |
| `backend/services.py` と必要最小限の専用モジュール | 10枚生成、判定の保存・取得、教材固定、再学習から再プレビューへの共通処理、LoRA版の採用 |
| `backend/events.py`／キャラクター台帳 | 生成元と判定の対応、学習状況、版の履歴と現在採用版 |
| `backend/app.py` | 共通サービスをREST／MCPへ公開。入力値と画像の所属確認 |
| `backend/box.py`／`box/train.py`／必要な学習モジュール | foxへの教材転送、選好学習、学習結果の保存と実効結果の確認 |
| `web/flows.js`／`web/jobs.js`／`web/api.js`／`web/style.css` | プレビュー画面、判定、再学習、前後比較、設定画への明示採用 |
| `tests/` | データ対応、学習契約、経路接続、画面操作の回帰試験 |

生成ジョブIDと画像IDを判定の識別子にし、画面上の連番や任意パスを保存先の根拠にしない。画像digest、キャラクターの作成識別、生成元LoRA、正・負プロンプト、seed、モデル・画風LoRA・強度、解像度・生成設定を固定する。判定はOK／NG／未判定、理由、更新版を持つ。競合する更新は上書きせず利用者に示す。

学習時には判定の固定版、対の一覧、元画像、学習前LoRA、学習設定を記録する。生成画像を利用者の元サンプルへ無断で混ぜない。既存の画像・台帳・LoRAは保持し、新しい学習結果を別名で保存する。旧データに判定がない場合は未判定とし、生成条件の記録が不足する旧ジョブは閲覧・判定保存までとし、新しい10枚の生成が必要な理由を示す。

画像MLの実行場所はfoxのWindowsネイティブ。メインサーバーは台帳と工程の所有者を維持する。第三者のsd-scripts checkoutを手編集せず、必要な拡張は本repoの学習モジュールとして版管理して配備する。互換性を保てない拡張が必要なら、必要性と差分を示して学習方式の判断を更新する。

## 受入条件

- 10枚の画像と各判定が保存・再表示・追加生成後も対応し、複数タブや通信失敗でも別画像へ付け替わらない。スマートフォン幅でも判定できる。
- OK／NGだけで学習データが作られ、両方が学習の数式と更新に使われる。未判定や異なるキャラクターの画像は混入しない。
- foxで1組の読込み、順伝播、逆伝播、LoRA保存・再読込み、ComfyUI推論を通す。基準モデルと旧LoRAが変更されないことを確認する。
- モデル、注文、推論設定を固定し、学習前・OKのみ追加学習・OK／NG選好学習を比較する。比較用seedと画像は学習に入れず、元画像単位で分割する。対象の髪型などの改善と、顔・衣装・画風の悪化の有無を全画像で目視確認する。
- ベルの既知の髪型不一致を回帰事例にし、異なる衣装・体形・人外を含む別事例でも確認する。改善しない場合は「学習が動いた」と「目的を達成した」を区別し、原因を特定して方式を改訂する。
- 比較画像・判定数・所要時間・VRAM・失敗を既存の閲覧面で確認できる。少数標本のOK率に母数と評価者を添え、10枚だけで統計的な確証やNGゼロ保証を宣言しない。画像の掲載範囲は元データの扱いに従う。
- 関連試験と実ブラウザー操作を先に通し、コード変更完了時に `uv run pytest` を一回実行する。公開版は既定ブランチに着地させ、本番反映後に判定保存・履歴・新版採用・設定画への接続を確認する。

## 実行上の判断

学習方式の成立を先に確かめ、その契約を使って保存・学習入口・画面を接続する。画面だけ先に完成扱いしない。保存と画面は同じ契約に密結合するため、最初は直列実装を選ぶ。第三者コードとの学習契約や本番反映の受入時には独立した反証を行う。GPU待ちと人による画像評価は外部条件として記録し、技術的な合否判断は実装担当が行う。

自動的な画像合否判定、設定画の自動生成、別モデルへの切替、手描き修復、全画面の作り直しは対象外。所要時間・必要な学習量・VRAMは最小試作の実測から見積もり直す。現時点でAnimaの選好学習を実行済み・効果確認済みとはしない。
