# 既存LoRAで注文の効果を比較する

2026-09-05。P2の受入に続き、計画済みのP3最初の4枚比較を実行する。利用者が衣装の方向を判断する区切りがあるため、同じ統括レーンを継続する。技術的な合否は親が判定する。

本番APIからベルの台帳を読み、専用の隔離台帳へ必要な名前・説明・呼び出し語・LoRA・画風設定を複製する。試験用の画像と記録は `evidence/user-intent-agent-20260905/private/p3-preview-01/` だけへ保存する。元の台帳・教材・LoRAは変更しない。

従来プロンプトと、P2で確認した3回目の実CLI応答によるプロンプトを、同じSeed 1/2・Anima Base・同じLoRA強度・解像度で2枚ずつ生成する。生成は既存ComfyUIで行い、再学習・モデル変更・追加課金・解釈の再呼出しは行わない。呼出し前にGPUが他の処理で使用されていないことを確認する。

比較で確認するのは、上下の分離と腹部の露出が参照に近づくか、顔・髪と描き方が保たれるか。製品へ衣装語をハードコードせず、記録済みのモデル応答を確認した開発実験として扱う。実際のワークフロー・生成記録・画像・所要時間を保存し、比較画面で全4枚を見せる。好きな1枚だけを成功例として抜き出さない。

この最初の比較は衣装の方向を決めるためのもの。未知素材への一般化、全工程の実装、再学習、本番反映は受入に含めたと偽らず、計画の後続として残す。
