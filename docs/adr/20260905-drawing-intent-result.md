# 一枚生成への注文接続の技術判定

2026-09-05。親が[契約](20260905-drawing-intent-design.md)の実装単位を受入と判断した。P5全体・本番配備・全体ゴールの完了ではない。

- キャラクター＋任意画風と画風単体で、確定したdrawingの注文を既存の解決処理からAnimaの肯定・否定文へ渡す。LoRAの役割と強度を維持する。
- 画面では採用済み注文と自由英文を明示的に選ぶ。残存英文への切替は行わない。共通条件または解釈IDと自由英文の同時使用は明示エラーとする。
- 肯定内容がある共通条件だけでの明示生成は許す。毎回新しい被写体・場面を必須にする制限は採らない。解決後の肯定内容が空の時だけ停止する。
- 実際の全文prompt、negative、LoRA列、確定IDと解決条件を生成jobへ保存し、画面とREST/MCPで同じサービスを使う。
