# 学習前の教材確認と履歴の契約

2026-09-05。計画P4の実装対象。GPU学習の実行合意は含めない。

画像コメント原文はsample.captionへ保持する。画像の観察を英語の教材説明へ変換した案はObservation.caption_enに出し、利用者が日本語の観察と英語を画像ごとに確認・訂正する。旧応答のcaption_en欠落は空文字として読めるが、未確認の原文を教材説明へ転用しない。

画像の観察確認と制作希望の採用は別操作にする。希望に質問や未接続の画風条件が残っても、観察だけを確認できる。観察確認はsample.training_captionへ保存し、原文と希望を上書きしない。同じ説明が解釈中に更新された場合は古い確認で上書きせず、読み直しを求める。

prepare_trainingは確認済みの画像説明だけから、画像の写し・呼び出し語を含む最終英文・観察・元参照・解釈jobを保存する。既存lora_train jobを確認待ちとして返し、ジョブ固有の教材フォルダを履歴として保持する。WebUIでは全教材を表示した後、その教材で学習する操作だけがGPUを起動する。

既存train_character_lora／train_style_loraはprepared_job_idを受け取り、凍結した同jobを実行する。明示的なAPI学習でIDを省略した場合もprepare_trainingを経由するが、未確認の画像説明があれば停止する。prepared_job_id指定時の学習ステップは準備済みjobの値を使う。対象台帳の作り直しと開始済みjobの再使用は拒否する。確認後に元画像・原文を編集しても、表示済み教材の写しは変更しない。新しい変更を学習へ含める操作は教材の作り直しとする。

学習後は最新台帳を読んで結果だけを反映し、途中のコメントを保持する。現在LoRAのtrain_jobから教材を表示し、旧記録に写しがない場合は来歴不明と表示する。キャラクターと画風の分離、学習器の起動・進捗処理は維持する。新ID体系、学習の自動起動、教材への希望の転記は実装しない。

検証は原文と教材の分離、全画像の確認、凍結した画像・英文の実行、二回目の教材作成で履歴を保持、学習中の編集保持、別対象拒否、REST/MCP共通入口、実ブラウザの確認・訂正・再表示を対象とする。実機学習は明示合意後の別実行とする。
