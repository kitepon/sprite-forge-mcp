# 設定画の構図とLoRAの影響を分ける

開始a4e7157、clean。前単位は6枚の比較と未達の記録を完了した進捗。現行Anima＋LoRAの製品方針と明示学習を保ち、親が診断用の実験だけを実行する。

比較元は前回の注文反映後3枚と保存済み実グラフ。正面と側面は「character reference, 」を肯定文から除く2枚、正面・側面・靴はLoRAノードのmodelとclip強度を0にする3枚を生成する。いずれも他の入力は元のまま。LoRA効果ゼロは原因切り分けの対照であり、製品設定として採用しない。元の3枚は再生成しない。

因果の範囲は同じseedにおける比較まで。単一の語句とLoRAの効果を同時に変更しない。見たい結果に合わせた再試行、再学習、別モデル導入はしない。どちらでも解決しない場合は未解明として次に必要な比較を決める。顔髪・衣装・画風の変化も観察へ含める。

MacのPythonからGPUへの直接接続は既知の失敗があるため、前回作成したメインサーバーの実験イメージを使う。コードと既存実グラフ・新結果だけを専用領域へ置き、本番台帳は変更しない。実行ハンドルと各グラフ・画像を残し、中断時に再起動しない。親単独で書き込み、条件の検査をfocused testで通してから5枚を直列実行する。全結果を閲覧面へ掲載し、技術判断を記録する。
