# コメント解釈の確認画面へ進む前の保存修理

2026-09-05の「良好で問題ないなら次に進めてくれるか」に対し、Terraの解釈案を人が確認・訂正する構成でP2へ進む。P1の残る省略を自動採用可能と判定したものではない。サブスクリプション限定、Sonnet除外、明示的な学習を維持する。

P2の最初の受入単位は、非同期処理中に保存されたコメントの消失修理とする。対象はキャラクター／画風の画像追加・学習、設定画生成、パネル描き直しの6経路。学習は開始時の教材を使い、完了時は最新台帳へ学習結果3項目だけを反映する。設定画生成は生成物、描き直しは当該パネルの修正だけを反映する。別の設定画へ差し替わっていた場合、その新しい設定画の日時を変えない。

画像取得前の台帳存在確認は維持し、取得後に更新用の台帳を読み直す。新しいID・キュー・ロック・再試行・別課金経路は追加しない。試験は一時データと疑似GPUだけを使う。本番更新と画像の効果確認は後続の計画された工程に残す。

本campaignは解釈・保存・生成・画像確認の受入が連鎖する統括レーン。今回の保存責務はFとして親が実装・裁定し、独立した読み取り反証を材料にする。書込みWorkerの委譲はない。Controlはこの保存修理の受入で作り、すでに実施した調査・再現・試験は実在する証拠で順に記録する。事前にControlを作ったとは扱わない。現在の工程正本は既存campaignのMarkdownとし、旧近代化のLattice計画へ追加せず、新しい工程管理の導入もしない。
