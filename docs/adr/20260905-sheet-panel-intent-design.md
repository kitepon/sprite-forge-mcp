# 設定画とパネルの注文を実行へ接続する契約

2026-09-05。P5の設定画・パネル修正の接続単位。親が同じサービスと画面を一括実装し、公開意味・保存競合の境界を既存の読取り専用検証者が反証する。並列writerは使わない。

既存Changeを維持し、sheet工程でもpanel_keyで23パネルの対象を指定できるようにする。persistentは全体の共通条件、panelは対象パネルへ今後も残す条件、this_runは今回限りとする。sheetのthis_runは対象panel_keyを省略すれば設定画全体、指定すればそのパネルだけ。panel工程の対象指定は注文対象との完全一致を維持する。他工程のpanel_keyは引き続きnullとする。

原文・参照画像順・既存共通条件に加え、当時のパネルの特徴別既定と保存修正を解釈へ渡す。エージェントは必要な対象別の確認案を返し、全23枚の完成文を毎回返す形式は追加しない。任意の衣装の語彙分解をコードに置かず、単品画の靴・頭飾りに必要な内容はエージェントが参照と注文から対象別に提案する。

共通条件、パネルの役割を定める既定、全体のthis_run、保存された個別修正、今回の対象指定を順に解決する。単品画は人物の顔・姿勢・衣装全体を継承しない。衣装単品はoutfitを継承し、頭飾り・靴は広いaccessory/outfitを機械的に切り分けず、対象別の確認案で変更する。同じ対象への保存案と今回案を併記した場合、保存案を次回へ残し、今回はthis_runを優先する。全身用と靴単品用が同じfeatureでもlistのまま保持し、対象ごとに解決する。

全体共通のpersistentは従来どおり確認時に採用する。対象パネルのpanel条件は、生成が成功した後に既存panel_overridesへ特徴別に保存する。this_runは生成記録だけに置く。保存時は生成開始時の同じパネルの修正と最新値を比較し、並行更新を古い内容で上書きしない。別パネルや別コメントは最新台帳へ差分を反映して保持する。

古い自由英文による全文置換は残す。解釈条件と任意の自由英文を同時に連結しない。保存済み自由英文と新しい解釈を合わせる場合は、エージェントに旧修正を渡して対象パネルの確認案へ取り込み、確認した対象別案へ置き換える。未解決の自由英文との混在は、生成開始前に明示エラーにする。

設定画と描き直しのREST/MCPへ省略可能なintent_job_idを追加し、同じサービスで検査する。生成jobには対象ごとの実際の肯定文・否定文・解決条件・解釈ID・LoRA・seedを保存する。WebUIは原文保存・解釈・対象と範囲の確認訂正・採用・生成・再表示まで接続し、既存の23パネル選択と変更前画像の履歴を維持する。

受入は最小試験で範囲・優先・保存を確かめ、公開REST/MCP、隔離ブラウザーの操作を確認する。実モデルの指示を変えた場合は既存の契約ログイン入口で応答を確認する。実機生成と本番配備は後続の効果確認へ残す。再学習、追加課金、Sonnet、モデル変更、本番台帳変更は行わない。
