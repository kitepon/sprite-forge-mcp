# 設定画の既定を特徴別に持つ契約

2026-09-05。P5の設定画・パネル接続に先行する挙動不変の実装単位。23パネルの名称・順番・寸法・生成文・別衣装・単品画という役割を維持したまま、既定の生成文を順序付きの特徴別断片として持つ。

現在の`Panel.tags`は一続きの文であり、共通の正面指定を側面へ足すと向きが衝突する。帽子の単品画へ衣装全文を足すと、人物の上着や靴まで入る。これは未接続部分へ単純追記した候補の問題であり、現在の本番がその合成を実行しているという報告ではない。

この単位は文字列を実行時に単語で分類しない。現在の23定義を一度だけ特徴別断片へ移し、元の順に連結して旧tagsを再現する。顔・髪・衣装・姿勢・表情・構図・被写体などの特徴名は既存の解釈形式と揃える。断片が同じ特徴を複数回持つ場合も、生成文では元の位置を保ち、特徴別表示では同じ特徴へまとめる。

英語自由文による既存パネル修正は、特徴へ推測分類せず全文置換のまま維持する。Panelの内部データ構造を変えるため、既存の2箇所の`_replace(tags=...)`を、生成文を作る関数の任意のtags引数へ移す。公開REST/MCPの引数・返却形式は変更しない。

親が定義・消費者・試験を一括して書く。同じPanel構造に依存するためwriterを並列化しない。公開意味の境界は既存の読取り専用検証者へ反証を依頼した。
