# NG指定と対象外保持の比較実験

2026-09-07。本人が調査提案に「ではその実験をしましょう」と承認した。実行工程と進捗の正本はLattice `preview-feedback-20260906 / 01-feasibility`。

NG画像の本人指摘を個別に保持し、除去指定がAnimaで該当する形を作るか確認してから、同じ除去指定によるESDと対象外保持を追加した学習を比較する。指定確認の成立を学習開始の条件とするため、受入が連鎖する統括レーンで扱う。判定は親が行い、外部の生成・学習完了だけを外部待ちとする。直接作業でありworker委譲はしない。

OK教材・合成教材を求めず、元LoRAと本番台帳を維持する。NG画像の未選択をOK判定へ変えない。特徴の抽出結果を無条件に消去対象へしない。学習量の増加だけで改善を図らない。

保持処理の候補は、凍結モデルのcross-attentionから髪の空間的な重みを求め、領域外の予測を元モデルへ近づける追加損失である。Recelerの概念局所化を参考にするが、Animaの既存LoRA・Flow予測へ適応する独自試作であり、Receler原論文の再現とは扱わない。空間重みは元モデルの生成画像に重ねて確認する。重みの定位が成立しなければ、保持成立を主張せず原因と観測を記録する。

除去指定、元モデル、LoRA強度、学習乱数・時刻、更新数・学習率、推論設定を両条件で固定し、独立した保持損失だけを比較対象とする。保持重みの初回は正規化された除去誤差と対象外誤差を等重みで比較する。最適値の主張はしない。未使用seedでNG再発、別のNGへの変化、顔・衣装・姿勢・構図を分けて全画像評価する。ユーザーの採否と実験担当の観察を区別する。

成果物は既存のファイル配信面へ全条件・全画像・失敗・判定を掲載する。実験用Python・focused test・全Python試験の最終確認を行う。本番への学習器採用や台帳切替はこの実験に含めない。

根拠：[Receler著者解説](https://jasper0314-huang.github.io/receler-concept-erasing/)、[著者学習コード](https://github.com/jasper0314-huang/Receler/blob/main/train_receler.py)。
