# 構図の原因比較を受入し、製品の無効化設定は不採用とする

## Decision

親は[実測](../../evidence/user-intent-agent-20260905/p5-sheet-causes.md)の全5件、比較元3件、指定変更とのグラフ一致、関連6試験、最終215試験、閲覧ページの掲載を確認し、診断単位を受け入れる。新しい製品設定を受け入れる判断ではない。

構図を説明する語句の除去だけでは正面・側面の複数人物を解消できず、この単独変更を修理として採用しない。LoRAを無効化すると正面の人数と靴の脚は改善したが、顔・画風・衣装も変わるため製品には採用しない。側面はLoRA無効化でも複数人物が残り、原因をLoRAだけに帰属する主張も棄却する。

Anima＋LoRA、ユーザーが確定した指示の適用範囲、明示的な学習を維持する。人間の基本品質が主要な受入であり、特殊な人外への対応を理由にその品質を下げない。再学習や構図の大幅な責務変更は今回行わない。

次は側面で未実施の二要因同時変更を比較し、相互作用を切り分ける。各条件1seedの限界を保持し、現在の結果で全キャラクターの品質やP3/P5/P6の完成を主張しない。全体ゴールを維持したまま、この診断単位を閉じる。
