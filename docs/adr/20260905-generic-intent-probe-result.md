# 汎用性検証から次の修理を選ぶ

2026-09-05。[4ケースの実測](../../evidence/user-intent-agent-20260905/p5-generic-probe.md)を根拠に、この調査単位を受け入れる。汎用ツールとしての品質は未達であり、製品・ゴールの完成判定ではない。

別の衣装を持つ男性、体格の大きいオーク、四足ドラゴン、手足なしスライムを、既存の同じ契約ログインとモデルで検証した。特定キャラクターの服へ固定する製品分岐は追加せず、参照番号の対応は成立した。男性・オークの2例で全体this_runが別衣装の役割を消すことと、基本ブーツの単品条件が次回へ残らないことを再現し、親と読取り専用検証者が欠陥として採用した。

前者は役割を保つ共通resolverの適用、後者は恒久の単品条件のscope選択を修理する。スライムの身体色分類と質問対象の不足も同じ解釈修理に含める。製品コードは本調査では変更していない。

固定23パネルを人外へ押し付けると、衣装なしの指定とパネル名・役割が両立しない。親は「キャラクターに合う構成を提案し、ユーザーが確認する」方式を推奨する。省略・差替え・名称変更を含む公開仕様の変更なので、この点をオーナーへ裁定依頼する。回答前に構成の変更は実装しない。

実機生成・再学習・本番機能配備は未実施。試験用説明引数は4ケースへ値が渡ることを含む6件のfocused testで確認した。未変更の製品全試験は繰り返さず、本調査からの後続修理と効果確認へ残す。
